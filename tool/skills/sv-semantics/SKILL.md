description: Exact meaning of SystemVerilog constructs that are easy to misread (IEEE 1800-2017): indexed part-selects (+:, -:), operator precedence, concatenation, widths and signedness, shifts, packed and unpacked arrays, blocking and non-blocking assignment, the clock cycle in which a value appears, resets, loops and generate, latches, and testbench sampling.
---
Rules (IEEE 1800-2017; vectors declared with a descending range such as `[127:0]`):

1. Indexed part-select: `v[b +: w]` is bits `b+w-1` down to `b`; `v[b -: w]` is bits `b` down to `b-w+1`. The width `w` is a constant; the base `b` may be an expression. In `v[A-1-:W]` the `-1` is a subtraction and `-:` is the operator: the base is `A-1`. Example: with `N = 128`, `d[N-8*k-1 -: 8]` is `d[127-8k : 120-8k]`, so k = 0 gives `d[127:120]`. The width may be a constant expression in parentheses, and part-selects may stand inside a concatenation: in `{v[A-B-1-:(C-D)], v[A-1-:B]}` both selects are `-:` selects (the `-1` before each `-:` is a subtraction); their widths are `C-D` and `B`, and they must add up to the width of the target. `-:` and `+:` are single operators written without a space; a plain `:` (as in `v[7:0]`) is a range select, whose second number is the lowest bit, not a width.
2. Which bits a part-select covers is known only after the base expression and the width are evaluated with the parameter values; an expression with parameters cannot be judged from its shape alone.
3. Concatenation `{a, b, c}`: `a` becomes the most significant part. `{4{x}}` repeats `x` four times.
4. Width: assigning a narrower value to a wider target extends it with zeros if the value is unsigned and with copies of its sign bit if it is signed; assigning a wider value to a narrower target drops the upper bits. The width of an operation is set by its context (the widest operand and the target).
5. Signedness: if any operand of an operation is unsigned, the whole operation is unsigned (for example, a signed `-3` compared with an unsigned `1` is compared as an unsigned value). An unsized decimal constant such as `1` is a signed 32-bit value.
6. Shifts: `>>` and `<<` are logical shifts (fill with zeros); `>>>` on a signed value is an arithmetic right shift (fills with the sign bit); on an unsigned value `>>>` fills with zeros.
7. Precedence, from higher to lower among common operators: unary, `* / %`, `+ -`, `<< >> <<< >>>`, `< <= > >=`, `== !=`, `&`, `^`, `|`, `&&`, `||`, `?:`. So `a & b == c` is `a & (b == c)` and `a << 1 + b` is `a << (1 + b)`.
8. Arrays: in `logic [7:0] s [4][4]`, `[7:0]` is packed (bits of one element) and `[4][4]` is unpacked; `s[i][j]` is one 8-bit element, first unpacked index first. `[4]` means `[0:3]`.
9. Blocking `=` (as in `always_comb`): statements run in order; a later statement sees the value written by an earlier one in the same evaluation, and a statement that reads a variable before the statement that writes it in this evaluation sees the value left by the previous evaluation (not 0). Example: in `always_comb begin a = b + 1; b = c; end` the read of `b` sees the old `b`. The same holds inside loops: an iteration that reads an array element which a later iteration writes sees the old element; list, for each read, whether its write comes earlier in the evaluation order. In Python keep such a variable between evaluations instead of starting it from zero. A signal assigned in `always_comb` is combinational: in each clock cycle it is a function of the register values and inputs of that cycle.
10. Non-blocking `<=` (as in `always_ff @(posedge clk)`): all right-hand sides are evaluated with the values before the edge; the registers take their new values after the edge. If the same register gets several non-blocking assignments at one edge, the last one takes effect.
    The same holds for a line you add to a Python model of the RTL (a switch, a new condition): inside one edge it reads every register, also a register of a module instantiated below, with the value before the edge. In a model that calls the step of a lower module inside its own step, take the lower module's register values before that call. A new signal that a module reads from a module below is a port which the lower module drives from its registers.
11. Cycles: call cycle k the time between rising edge k-1 and rising edge k. During cycle k every read of a register gives the value stored at edge k-1. A value computed combinationally from registers in cycle k is stored in its destination register at edge k and can be read from it in cycle k+1.
12. `if / else if / else` is a priority chain evaluated with the values of the current cycle. In `always_ff`, a register that no taken branch assigns keeps its value.
13. Latches: in `always_comb`, a signal that some path leaves unassigned, with no default assigned to it earlier in the block, infers a latch; this includes an `if` without `else` and a `case` that does not cover every value and has no `default`.
14. Asynchronous reset `always_ff @(posedge clk or negedge rst_n) if (!rst_n) ...`: the reset branch acts as soon as `rst_n` falls, not at a clock edge.
15. Loops: a `for` loop inside an `always` or `initial` block runs its iterations one after another each time the block executes (its bound may be a variable in simulation; synthesis unrolls it). A `generate for` loop, and a `generate if` condition, are evaluated when the design is elaborated: a `generate for` makes one copy per iteration with a constant `genvar`, a `generate if` keeps only the chosen branch.
16. Testbench timing: inputs set at a falling edge are seen by the design at the next rising edge; `@(posedge sig)` waits for a change of `sig` from 0 to 1.
17. Unknown values (X). Each bit, and so each element of an array, carries its own X; one unknown element does not make the others unknown. A part-select or index outside the vector reads X. A bitwise or arithmetic operation or a comparison with an X operand gives X (except `0 & X` = 0 and `1 | X` = 1). An `if` whose condition is X takes the `else` branch (no `else`: nothing is assigned). A `case` whose selector has an X bit matches no item and takes `default` (no `default`: nothing is assigned). So a value that passes through a `case` with a `default`, or through an `if`/`else` that assigns constants, is known again after it.
18. Division and remainder: `/` on integers drops the fraction towards zero, and the result of `%` has the sign of its first operand: `(-1) % 4` is `-1`, `(-5) / 4` is `-1`. In Python `//` rounds down and the result of `%` has the sign of the second operand: `(-1) % 4` is `3`, `(-5) // 4` is `-2`. An expression that can become negative (an index such as `(i - k) % N`, a difference of two counters) therefore gives another value in SystemVerilog than the same text in Python; in SystemVerilog add the modulus before the remainder is taken (`(i - k + N) % N`), or write the non-negative value another way. A negative index is out of range (point 17).
